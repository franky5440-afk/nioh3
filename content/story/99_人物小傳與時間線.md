## 一、人物短傳

| 人物 | 短傳 |
|------|------|
| **德川竹千代（後・家光）** | 家康之孫；繼任日少主。自幼能見守護靈。經跨時代征戰悟「何謂將軍」，終改名家光，為三代將軍；兼武士與忍者守太平。 |
| **德川國松** | 弟；妒恨繼任，受叢雲暗染，終與蛭子融合。敗後面臨處刑或饒恕；赦則為影武者。 |
| **草薙** | 竹千代守護靈；跨時代傳送之源。經靈樹賦能復真姿，得以摧毀靈魂石。 |
| **叢雲** | 腐敗守護靈；附國松／蛭子一側。 |
| **蛭子** | 卑彌呼之弟；靈魂石與裂隙之源。天守決戰敗後殺卑彌呼並與之消失。 |
| **卑彌呼／阿龍** | 邪馬台女王；幕末化名阿龍。終為蛭子所殺，魂於遠方觀望。 |
| **齋藤阿福** | 乳母兼陰陽導師。開場線中護主而死；改命後得生。 |
| **柳生宗矩／服部半藏** | 開場據稱亡於國松；改命後得救。戰國另有第二代半藏。 |
| **本多忠勝／德川家康／井伊直虎** | 1572 戰國線關鍵；直虎說明熔爐與靈魂石。 |
| **源義經／靜御前／源賴朝** | 平安線；人妖和平與武力路線衝突；靈樹幼枝由此而植。 |
| **高杉晉作／沖田總司／德川慶喜** | 幕末線；慶喜悲憤被靈魂石所乘。 |

## 二、時代軸（骨架）

```
247  彌生：卑彌呼 vs 蛭子；永恆裂隙；叢雲附國松之因
 │
1190 平安：鞍馬／義經／賴朝；淨三障；植靈樹幼枝
 │
1572 戰國：忠勝／家康／直虎；二俣・三方原・濱松熔爐／信玄
 │
1622 江戶繼任日：國松襲城 → 草薙傳送 →（回歸）敗國松→蛭子融合
 │                      └─ 卑彌呼送往未來
1864 幕末：高杉／阿龍；皇宮熔爐（沖田・慶喜）→ 靈樹成・草薙真姿
 │
1622 終盤：改命救宗矩／半藏／阿福；異界江戶；天守決戰蛭子
 │
     └─ 斬／赦國松 → 竹千代改名家光（三代將軍）；卑彌呼魂遠觀
```
