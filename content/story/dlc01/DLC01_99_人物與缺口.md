## 一、人物小傳（短）

| 人物 | 小傳 |
|------|------|
| **德川竹千代／家光** | 本篇終局後已就任三代將軍。DLC 自夢中被見知らぬあやかし引至 1651 慶安未來江戶；彼處「未來家光」已亡。敘事中性，不強調外貌性別。A 斬／B 赦皆可接本卷。 |
| **草薙** | 守護靈。開卷與傳送／振刀相關；引導之鏡並見於試玩層——機制細節仍缺。 |
| **柳生十兵衛** | 宗矩之子；與竹千代為兄弟弟子。可協力亦可交刃／擋路；獎盃有勝利並和解表述。隻眼劍豪。 |
| **ロドリゴ** | エスパーニャ使節。追可疑エスパーニャ之女與アムリタ（精華／靈石）流向；與叛軍錬金勢力周旋。 |
| **由井正雪** | 亂魁。史實慶安之變底；遊戲借地獄之力起事。訪談三重義之「核心人物」公開推測對象；道灌山決戰，討後驅散該山地獄。完整執念對白缺。 |
| **金井半兵衛** | 張孔堂可考討伐對象（獎盃「大逆之忠」）。細節、對白、與正雪關係結構缺。 |
| **國松／影武者** | 本篇雙結局分歧相關。DLC 公開未詳其是否露面；本卷中性不寫死。 |
| **一目連、垢嘗等** | 公開新敵名；戰鬥彩可不強入主線正文。 |

## 二、與本篇雙結局（中性說明）

- 本篇第十三回：**A 斬（處刑）／B 赦（影武者）** 皆以就任**家光**收束。
- 本 DLC **共通前提＝已就任將軍**；兩結局皆可進入慶安後日譚。
- 正文避免只認單一結局為正史；若未來補到國松／影武者戲份，於依據欄分注。
